## 兼容入口

「阅览室设置 → 打开完整管理界面」提供经典阅读器、ComicRead 和高级选项。经典阅读器与 2.0 共用每本书的单页、双页、连续模式；全局像素宽度与高级配置继续由兼容入口保存。2.0 阅读工具使用每本书的方向、缩放与适配偏好。安卓导出、局域网扩展和整库自动 OCR 按产品计划进入后续版本评估。

## 本机验证与发布门槛

全量入口为 `npm run test:all`，包含工程检查和项目服务／界面／真实 Electron 回归。历史的真实书库图库脚本保留独立入口。新测试在临时目录生成中性书页，验证文件哈希；回收行为在测试专用目录模拟。

2.0 开发预览基线曾通过 10 项工程检查与 53 套项目回归，生成的 Windows 预览程序也已完成隔离启动、续读、房间往返和重启检查。选中书返回路径在该基线之后做了专项回归。详细结果与性能采样见[产品迭代计划](颜如玉2.0产品标准与迭代计划.md)。产品标准中的第二台低配 Windows 设备、干净账户安装包检查及 6 人任务观察，仍需相应设备与试用者提供实测记录。
