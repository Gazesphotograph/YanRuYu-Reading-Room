## 经典功能退役验收

| 原入口或操作 | 当前入口及验收口径 | 复测 |
| --- | --- | --- |
| 以经典界面启动 | 当前渲染器读取旧界面标志，首次进入工作区后记住选择。默认进入书库，已选启动页优先 | `test-reading-bridge.cjs`、`test-management-desktop.cjs` |
| 经典组合条件 | 在相同四本样书上核对退役前记录的书名集合，验证目录边界、排除条件、任选条件与跨视图返回 | `test-catalog-filter-smoke.cjs` |
| 原版内置阅读器与 ComicRead | 在书籍详情续读同一本书，保留原始迁移快照。每本书单独保存模式、方向、封面独页、缩放与页内位置 | `test-reading-bridge.cjs`、`test-reading-tools.cjs`、`test-reading-archives-desktop.cjs` |
| 复制书页、取书页为封面、删页 | 阅读器「书页与切换」作用于当前页码。删除前显示页码供确认，文件夹图片进入回收站，压缩包删页前生成恢复点 | `test-management-desktop.cjs`、`test-safe-operations.cjs`、`test-data-protection-desktop.cjs` |
| 切换书籍 | 从阅读器按当前筛选结果切换上一本、下一本，可在系统设置中启用末页翻至下一本 | `test-reading-tools.cjs` |
| 选择外部阅读程序、托盘、元数据目录和局域网浏览 | 「系统与阅读设置」选择或恢复默认程序、元数据目录，保存托盘与共享开关。书籍详情控制本次使用内置或外部阅读器 | `test-workspace-management-ui.cjs`、`test-management-desktop.cjs`、`test-startup-tray.cjs` |
| 发布文件 | 构建清单和解压目录排查经典管理脚本、样式与 ComicRead；独立启动、备份恢复、历史升级使用隔离数据 | `test:engineering`、`release:audit`、`verify-upgrade-desktop.cjs` |

旧版的自定义 CSS、ComicRead 专属配置和后台整本图片缩放随其渲染器退役。阅读器现在按需显示原图，使用适配方式、全局单页宽度上限与单书缩放。旧版设置文件、旧备份格式及可配置的外部阅读程序继续受支持。

## 本机验证与发布门槛

全量入口为 `npm run test:all`，包含工程检查和项目服务／界面／真实 Electron 回归。历史的真实书库图库脚本保留独立入口。新测试在临时目录生成中性书页，验证文件哈希；回收行为在测试专用目录模拟。

本次退役验收通过 55 套工程、服务、界面及 Electron 回归。Windows 预览包另行验证首次扫描、阅读、重启、四种数据布局的历史升级，以及恢复中断、只读目录和离线书库。产品标准中的第二台低配 Windows 设备、干净账户安装包检查及 6 人任务观察，仍需相应设备与试用者提供实测记录。
