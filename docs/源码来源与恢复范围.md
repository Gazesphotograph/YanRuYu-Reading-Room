## 当前构建来源

| 部分 | 维护位置 |
| --- | --- |
| 窗口、书库、扫描、SQLite 与文件处理 | `resources/app/index.js`、`modules/` 和 `fileLoader/` |
| Vue 启动入口、组件和状态 | `src/renderer/`，Vite 生成 `resources/app/dist/app/` |
| 书桌、书库、3D 阅览室、阅读器和恢复界面 | `resources/app/dist/room*.js` 及同目录下的模块和样式 |
| 7-Zip | `resources/extraResources/` 中的二进制及随附许可证 |

旧配置、备份和阅读进度的迁移由现有渲染器及主进程完成。关键任务的入口和复测脚本见[功能验收矩阵](颜如玉2.0功能验收矩阵.md)。

## 可审计发布

Git 和发布都使用允许列表，生产依赖只从 `resources/app/package-lock.json` 在新 staging 安装，不复制现用程序的 node_modules。发布清单只包含相对文件名与哈希，来源说明不包含本机登录信息。输出独立存放在 `out/`，不会覆盖任何现有程序或数据。
