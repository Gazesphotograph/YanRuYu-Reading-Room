## 已验证的 EXE 优化

当前 `exhentai-manga-manager.exe` 的逻辑大小为 246,185,472 字节（234.78 MiB），主要包含 Electron 44.3.0 的 Chromium 与 Node.js 运行时。使用 Windows 自带的 LZX 透明文件压缩后，实际文件分配空间为 104,349,696 字节（99.52 MiB），节省 141,835,776 字节，约 57.6%。

压缩前后文件 SHA-256 均为 `a0a674ad6c99a82b34b739bfe8691813890d12b9f73316697942ef422142672b`，可直接运行。实际占用由 Windows `FILE_STANDARD_INFO.AllocationSize` 读取；不把普通文件的逻辑长度冒充磁盘分配空间。

此优化改变磁盘存储方式，不改变逻辑文件长度，也不降低运行内存需求。复制或 ZIP 解压可能丢失压缩属性，附带的 `优化程序磁盘占用.ps1` 可重新应用；非 NTFS 分区仍能按普通文件运行。

## 发布流程优化

- 发布只复制中英文四份 Electron 语言资源，保留原有图形、音频、字体和回退组件。
- 从新安装的生产依赖中移除测试、示例、文档、类型声明与源码映射，保留运行 JavaScript、数据、原生模块、包信息和许可证。本轮构建移除 1,709 个文件，12,433,345 字节。
- 新建程序目录后应用无损压缩；同时生成 ZIP 并进行完整性验证。构建清单核对源码与可执行文件哈希，并验证不含私人数据库、封面、配置、整理日志或导入文本。
- 压缩脚本只允许当前程序或独立发布目录，检查路径边界及目录联接。发布报告只描述被测安装目录，不能代表 ZIP 解压后自动保留相同占用。
