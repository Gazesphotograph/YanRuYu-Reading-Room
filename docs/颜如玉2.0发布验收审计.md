## 继续执行的工程检查

在发布前保持原范围，继续补齐选中书被删除／隐藏时的返回路径、三个数据目录模式的真实历史升级，以及当前源码快照的性能和打包验证。全量命令为 `npm run test:all`；结果包含每套状态、耗时和实际构建源哈希。

设备与试用者要求保留为发布门槛。此审计不把缺少直接证据的项目计为完成，当前交付仍为开发预览。
