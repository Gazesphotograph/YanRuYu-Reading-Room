## 继续执行的工程检查

发布前继续补齐各目录布局的升级故障验证，以及当前预览快照的性能采样。全量命令为 `npm run test:all`，结果包含每套状态、耗时和实际构建源哈希。历史升级专项使用实际发布包，单独运行方式见[数据目录与隔离验证](数据目录与隔离验证.md)。

设备与试用者要求保留为发布门槛。此审计不把缺少直接证据的项目计为完成，当前交付仍为开发预览。
